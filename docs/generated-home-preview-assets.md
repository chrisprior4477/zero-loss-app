# Homepage preview imagery

These WebP files are generated, fictional sample media for the Crew and winner-story layout preview. They are not photographs of Zero Loss customers or verified winners. Replace winner-story previews with permissioned, verified media before treating the section as a real testimonial surface.

## Tool

Built-in image-generation tool. The selected PNG contact sheets were cropped and compressed into the files under `public/images/home/crew/` and `public/images/home/winner-previews/`.
